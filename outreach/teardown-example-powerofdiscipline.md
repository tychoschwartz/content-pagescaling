# Worked example — Teardown DM for @powerofdiscipline_

A real teardown, kept as a template. The pattern works for any page that's
**growing but visually inconsistent**: lead with genuine respect for the real
number, name the specific gap you can see, tie it to a weak metric, then prove
it with a same-niche managed page that beats them on that exact metric.

## The reusable pattern (for the next prospect)

1. **Respect the real number first** — never open by insulting a growing page.
2. **Name the specific visible gap** — prove you actually looked (list what you
   see on the grid).
3. **Tie it to a weak metric** — engagement %, posting gaps, flat curve.
4. **Prove it with a same-niche managed page** that beats them on that metric —
   one honest, verifiable number.
5. **Soft close with a concrete next step** — "want me to mock up a week?"
