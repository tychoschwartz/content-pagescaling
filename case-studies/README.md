# @pagescaling — Case studies

Data-driven case-study cards in the ps. house style. Every number is real and
verifiable; each card carries an **as-of date (22 Jul 2026)** so the stats read
as a point-in-time snapshot, and the client's own page logo.

Re-render after editing: `node build/casestudies.mjs`.

> Note on sources: 01–03 are follower-growth stories verified on Social Blade.
> 04 is a reach/views story from the account's own Instagram Insights (follower
> delta intentionally not featured — it's a discovery/virality case).
