# @pagescaling — Instagram posts

Five posts built in the exact house style of the Pagescaling website
(`launch-own-website-ruflo/pagescaling`): near-black blue-biased ground
`#08090b`, off-white ink `#eef2f7`, light-blue accent `#5cc6ff`, verified
green `#37d67a`, subtle blue grid + aurora glow, PS mark, and the
**Fraunces / Inter / JetBrains Mono** type system.

All images are **2160×2700 px** (2× the 1080×1350 Instagram portrait ratio —
export as-is; Instagram downscales cleanly and stays crisp).

To re-render after editing copy, edit `build/slides.mjs` and run
`node build/build.mjs`.
